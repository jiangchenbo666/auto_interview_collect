# 八股底盘补充题

## 数据库索引原理

1. MySQL 索引为什么常用 B+ 树而不是 B 树或哈希表？
2. 聚簇索引和非聚簇索引有什么区别？InnoDB 主键索引为什么会影响二级索引？
3. 什么是索引覆盖？什么情况下可以避免回表？
4. 联合索引的最左前缀原则是什么？哪些写法会导致索引失效？
5. 慢查询定位时，你会如何结合 explain 分析 type、key、rows 和 Extra？

## Linux 内核态与用户态

1. Linux 为什么要区分用户态和内核态？
2. 系统调用是什么？一次 read/write 大致会经历哪些用户态到内核态的切换？
3. 进程、线程和协程有什么区别？测试开发中怎么理解它们对并发压测的影响？
4. 上下文切换为什么会带来性能开销？如何从测试角度观察这种问题？
5. Linux 文件权限、进程权限和安全测试中的越权问题有什么关联？

## TCP/IP 握手与网络基础

1. TCP 三次握手的过程是什么？为什么不是两次握手？
2. TCP 四次挥手的过程是什么？TIME_WAIT 状态有什么作用？
3. TCP 和 UDP 的区别是什么？接口测试和性能测试中分别要关注什么？
4. HTTP Keep-Alive 和 TCP 连接复用有什么关系？
5. HTTPS 握手大致做了什么？证书校验失败时测试应该关注哪些点？

## Docker Namespace 与 Cgroups

1. Docker 容器和虚拟机的核心区别是什么？
2. Docker Namespace 解决了什么隔离问题？常见 Namespace 有哪些？
3. Cgroups 解决了什么资源限制问题？CPU、内存限制失效会带来什么风险？
4. 容器内进程为什么能看到自己像是在独立系统里运行？
5. 做安全测试时，容器逃逸、挂载敏感目录和特权容器分别有什么风险？
